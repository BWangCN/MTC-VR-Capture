# MTC-VR-Capture — branch `vr-g1-realtime-streaming`

> This branch is **separate** from `master`. `master` holds the PICO 24-point SMPL
> **capture + trimming** code. This branch holds the **real-time PCVR streaming**
> stack: the `VR_G1_RealTime_PC` Unity project and the `ALVR_Streaming` setup.

Large binaries (scanned-object `.obj`/textures, APKs, the ALVR streamer/exe/zip) are
stored via **Git LFS** (see `.gitattributes`). You need `git lfs` installed to clone
with the binaries: `git lfs install` then a normal `git clone`/`git checkout`.

## Not committed (regenerable / build cache)
Unity `Library/`, `Temp/`, `obj/`, `Logs/`, `UserSettings/`, `*.csproj`, `*.sln`
(see `.gitignore`). Regenerated by Unity on first open.

## How the streaming runs (quick recap)
1. Start **SteamVR** on the PC.
2. Launch **`ALVR_Streaming/pc_streamer/streamer/ALVR Dashboard.exe`** — it registers the
   ALVR driver into SteamVR.
3. Install `ALVR_Streaming/headset_apk/alvr_client_android.apk` on the headset, connect it
   over WiFi (see `ALVR_Streaming/SETUP_WIFI.md`).
4. Open `VR_G1_RealTime_PC` in Unity for the real-time G1 / real-env streaming app; see the
   runbooks in that folder.
